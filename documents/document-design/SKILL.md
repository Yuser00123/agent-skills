# Document Design Skill

## Purpose

Design professional, readable, visually coherent documents and digital artifacts.

This skill controls presentation quality across:

- PDFs
- DOCX
- PPTX
- XLSX
- Reports
- Resumes
- Certificates
- Study materials
- Business documents

It complements format-specific creation skills.

---

## Core Principle

Design should improve communication, not merely decoration.

Prioritize:

```text
Clarity
→ Hierarchy
→ Consistency
→ Readability
→ Accessibility
→ Aesthetics
```

---

## Design System

Before creating a substantial artifact, define:

### Typography

Determine:

- heading font
- body font
- title size
- heading sizes
- body size
- caption size

Keep the hierarchy consistent.

---

### Spacing

Define:

- page margins
- section spacing
- paragraph spacing
- card padding
- line spacing
- slide spacing

Consistent whitespace makes documents easier to scan.

---

## Visual Hierarchy

Every page/slide should make the following clear:

```text
What is this?
↓
What is important?
↓
What should I read next?
```

Use:

- size
- position
- whitespace
- grouping
- alignment

to establish hierarchy.

---

## Alignment

Use consistent alignment systems.

Prefer:

```text
left edges aligned
consistent columns
consistent margins
```

Avoid arbitrary positioning.

---

## Whitespace

Whitespace is functional.

Use it to:

- separate sections
- emphasize important information
- prevent visual overload
- improve scanning

Do not fill every empty space.

---

## Color

Use a limited palette.

Define:

```text
Primary
Secondary
Accent
Background
Text
Muted text
```

Do not introduce random colors throughout the document.

For accessibility, ensure sufficient contrast.

---

## Components

Create reusable visual components.

Examples:

```text
Section heading
Info card
Warning box
Metric card
Table style
Callout
Footer
Caption
```

Reuse components instead of manually redesigning every section.

---

## Images

Images should serve a purpose.

Use them to:

- explain
- demonstrate
- provide evidence
- create context
- improve comprehension

Avoid irrelevant decorative images.

---

## Tables

Tables should be optimized for scanning.

Use:

- clear headers
- consistent alignment
- reasonable column widths
- concise cell content
- whitespace

Avoid extremely dense tables when information can be represented more clearly another way.

---

## Charts

Select chart type based on the question.

Examples:

```text
Comparison → bar chart
Trend → line chart
Composition → stacked/bar chart
Distribution → histogram
Relationship → scatter plot
```

Do not use charts simply because they look impressive.

---

## Accessibility

Design for users with different needs.

Consider:

- readable font sizes
- contrast
- logical structure
- descriptive headings
- alternative text
- meaningful labels
- avoiding color-only communication

---

## Format-Specific Design

### PDF

Focus on:

- page composition
- typography
- print/readability
- pagination

### DOCX

Focus on:

- editable structure
- styles
- headings
- navigation
- printable layout

### PPTX

Focus on:

- visual storytelling
- minimal text
- large visuals
- presentation distance

### XLSX

Focus on:

- data scanning
- hierarchy
- filters
- useful dashboards
- calculation clarity

---

## Audience Adaptation

Design should depend on audience.

### Student

Prioritize:

- clarity
- examples
- diagrams
- revision-friendly structure

### Technical audience

Prioritize:

- architecture
- precise terminology
- technical diagrams
- evidence

### Executive audience

Prioritize:

- concise conclusions
- metrics
- decisions
- visual summaries

### General audience

Prioritize:

- plain language
- intuitive organization
- minimal jargon

---

## Anti-Patterns

Avoid:

- excessive gradients
- excessive shadows
- tiny text
- dense paragraphs
- random colors
- inconsistent fonts
- unnecessary borders
- decorative charts
- excessive icons
- misaligned elements
- visual clutter

---

## Design Review

Before completion ask:

```text
Can the main point be understood quickly?

Is the hierarchy obvious?

Is anything unnecessarily dense?

Are elements aligned?

Is the typography consistent?

Are visuals meaningful?

Is the artifact accessible?

Does the design match the audience?
```

---

## Completion Criteria

Design is complete when:

- Visual hierarchy is clear
- Typography is consistent
- Spacing is coherent
- Alignment is consistent
- Colors are purposeful
- Content is readable
- Visuals support communication
- Accessibility has been considered
- The design matches the target audience

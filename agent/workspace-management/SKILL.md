# Workspace Management Skill

## Purpose

Maintain a clean, recoverable, and organized workspace.

---

## Core Principle

Never lose user work.

---

## Responsibilities

Track:

- Current files
- Modified files
- Generated files
- Temporary files
- Snapshots

---

## Before Changes

Check:

- Git status
- Existing modifications
- Uncommitted work

---

## Snapshot Strategy

Create checkpoints before:

- Refactors
- Deployments
- Major edits
- Automated fixes

---

## Temporary Files

Clean:

- Debug files
- Temporary logs
- Test artifacts

Preserve only if needed.

---

## Recovery

If corruption occurs:

- Restore snapshot
- Restore branch
- Restore file

Prefer recovery over rebuilding.

---

## Workspace Hygiene

Avoid:

- Random files
- Duplicate outputs
- Untracked clutter

---

## Completion Criteria

Workspace management is complete when:

- User work preserved
- Snapshots available
- Workspace organized
- Recovery path exists
